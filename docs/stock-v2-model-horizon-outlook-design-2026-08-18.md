# StockV2 模型多周期预期设计

> 日期：2026-08-18
>
> 状态：已实现
> 适用：机会发现、策略生成、组合哨兵

## 目标

StockV2 的分析结果需要直接回答短、中、长期的条件预期，例如“未来 5 个交易日，模型估计上涨概率为 68%，预期价为 10.50”。该结果不是收益承诺，也不是由技术指标机械换算的概率。

本能力复用现有 Agent 任务，不新增调度、模型绑定、配置项或事后验证任务：

```text
机会发现 -> 候选三周期预测 -> 策略生成上下文
策略生成 -> 草案三周期预测 -> 跨周期操作剧本
组合哨兵 -> 持仓三周期预测 + 组合三周期预测 -> 持仓操作计划
```

Phantom Lancer 不负责这些预测的事后校准或胜率统计。外部分析服务可以直接读取现有数据与完整 Agent 上下文做独立复盘，主服务不感知该流程。

## 分析边界

- 概率、方向、预期价、价格区间、目标触及概率、预期收益和模型置信度都由模型填写。
- 模型应综合行情、成交量、资金、市场与行业状态、消息脉络、基本面、估值、催化、拥挤度、冲突证据和数据新鲜度。
- 确定性代码只负责信任边界：要求三个周期齐全，检查数值有限、概率在 0 到 1、价格为正、预期价位于区间内，并裁剪过长文本。
- 确定性门、候选评分和技术指标可以作为模型证据，但不能直接映射为预测概率。
- 数据缺失时允许模型作出条件估计；必须同步标记数据质量、列出不确定性并降低模型置信度。

## 固定周期

| horizon | 交易日 | UI 名称 |
|---|---:|---|
| `short` | 5 | 短期 |
| `medium` | 20 | 中期 |
| `long` | 60 | 长期 |

周期固定是输出协议，不是运行时配置，因此不在前端增加配置项。

## 单标的输出

`ModelHorizonOutlook` 使用嵌套 camelCase 字段：

- `asOfPrice`：模型判断所依据的当前可比价格。
- `probabilityUp`：周期结束时高于基准价的模型概率。
- `probabilityOutperform`：相对市场或合适基准跑赢的模型概率。
- `expectedPrice` / `expectedReturnPct`：模型期望值。
- `rangeLow` / `rangeHigh`：模型认为有意义的条件价格区间。
- `targetPrice` / `targetProbability`：周期内触及目标价的模型概率。
- `downsideRiskPct`：模型评估的主要下行幅度。
- `confidence`：对该周期分析本身的信心，不等于上涨概率。
- `thesis`、`invalidConditions`、`uncertainties`：判断依据、失效条件和未决信息。
- `dataQuality`：`healthy`、`degraded` 或 `insufficient`。

机会候选在 API 中使用 `horizonOutlooks`。Agent report 和组合哨兵 action plan 外层仍遵循各自既有 snake_case，字段为 `horizon_outlooks`。

## 组合输出

组合哨兵的 `portfolio_outlooks[]` 对每个被检查组合返回三个 `ModelPortfolioHorizonOutlook`：

- 盈利概率与跑赢概率。
- 预期收益和收益区间。
- 预期最大回撤。
- 组合层摘要、失效条件、不确定性、数据质量和模型置信度。

模型必须考虑持仓集中度和相关性，不能简单平均或相加单票概率。

## 策略联动

机会候选的预测作为后续策略生成的输入证据。策略生成的组合评审步骤可结合更新的数据修正预测；最终格式化步骤必须原样传递评审结果，不重新计算。

每条新策略规则包含：

- `horizon`：`short`、`medium`、`long` 或 `cross_horizon`。
- `forecast_basis`：说明该动作如何响应相应周期预测。

模型应输出一组协调的操作剧本。例如短期偏弱、长期偏强时，可以选择等待回撤后建仓，而不是同时输出无解释的立即买入和立即减仓。

## 兼容与展示

- 机会发现、策略生成和组合哨兵分别升级到 report v2、v2、v3。
- 历史结果继续读取；没有新字段时 UI 显示“旧记录无预测”，不做推断补齐。
- 列表仅展示 5 日上涨概率、预期价和目标触及概率。
- 详情展示三周期概率、区间、目标、下行风险、判断依据、失效条件、不确定性和数据质量。
- 数据质量降级和不足使用 warning/danger 语义色高亮，但不把概率用颜色伪装成确定结论。
